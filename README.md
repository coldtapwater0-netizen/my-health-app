# 플릭핏 (FleekFit) v2 — 멀티유저 개인 헬스 일지 PWA

별도 빌드나 유료 DB 없이 Google Sheets와 연동되는 **멀티유저 다크/라이트 개인 헬스 일지 PWA**입니다.

## v2 주요 기능
- **멀티유저 로그인 & 구글 시트 분리 저장**: 닉네임 + 4자리 PIN으로 사용자별 운동·루틴·보충제·인바디 데이터를 Google Sheets에 완전히 분리 저장·동기화
- **화면 테마 전환**: 다크 모드 / 라이트 모드 / 시스템 설정에 따름 지원
- **강화된 운동 기록**:
  - 중량 + 맨몸 운동(횟수 / 시간 초 단위) 지원
  - 세트 유형 전환(일반 / `W` 워밍업 / `D` 드롭세트) — 워밍업 세트는 총 볼륨·1RM 통계 제외
  - 이전 기록 경신 시 `PR` 신기록 배지 자동 표시
  - 상단 **바벨 원판(플레이트) 계산기** 모달 (20kg/15kg/10kg 바벨, 25kg 원판 포함 옵션)
- **데일리 케어**: 보충제 원터치 하루 체크(기본 4종 + 커스텀 추가) & 체중·골격근량·체지방률 기록
- **기록·성장**: 운동/보충제 **출석 캘린더**, 총 볼륨/종목별 1RM/부위별 자극 비중 + **체중·골격근량·체지방률 추이 그래프**

## 로컬 실행 (Windows)
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
브라우저에서 `http://127.0.0.1:4173` 접속
